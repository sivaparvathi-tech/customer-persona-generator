# AI Customer Persona Generator

An AI-powered tool designed for marketers to generate realistic customer personas from a product description and target market.

## Problem Statement

Create a tool where marketers describe their product and target market, and the AI generates detailed customer personas including demographics, pain points, goals, and preferred channels.

The tool also provides a comparison view across multiple personas and allows users to export personas as shareable one-page persona cards.

## Features

- Generate multiple AI-powered customer personas
- Demographics
- Pain Points
- Goals
- Preferred Channels
- Persona Comparison View
- One-page Persona Card Export
- Multilingual interaction and persona generation

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## Project Flow

Product Description + Target Market  
↓  
AI Customer Persona Generation  
↓  
Multiple Customer Personas  
↓  
Persona Comparison  
↓  
One-page Persona Card Export
